# CompilerLab —— 《编译原理》实验三：综合实验

广州大学《编译原理》探索性实验（三）：实现一个小型语言的编译系统，从词法分析一路做到解释执行。
用 C# / .NET 9 / WinForms 编写，全部算法自行实现，不依赖任何编译器框架。

## 编译流水线

| 阶段 | 说明 |
| --- | --- |
| 词法分析 | 关键字、标识符、整型与实型常量（含指数形式）、运算符与界符、两类注释；一次运行报出全部词法错误并给出行列号 |
| 语法分析 | 小语言文法的 SLR(1) 分析（63 个项目集，无冲突），输出项目集规范族、ACTION / GOTO 表与逐步分析过程 |
| 语义分析 | 分层符号表与作用域链；类型提升（int → real）；重复声明、未声明、类型不相容、条件非布尔等检查 |
| 中间代码 | 生成四元式 `(op, arg1, arg2, result)`，含临时变量 t1…、标号 L1… 与 `jz` / `j` / `label` 等控制转移指令 |
| 解释执行 | 预扫描建立标号跳转表，按程序计数器顺序执行四元式，输出程序运行结果与变量终值 |

## 语言特性

- 类型：`int`、`real`；声明与赋值
- 控制流：`if`、`if-else`、`while`（语句体用 `{ }` 括起，避免悬挂 else 二义性）
- 输入输出：`read ( id ) ;`、`write ( expr ) ;`
- 表达式：`+ - * /`、关系运算 `< <= > >= == !=`、括号、一元负号
- 作用域：嵌套块，内层可声明与外层同名的变量（用存储名区分）

## 构建与运行

环境要求：Windows 10/11 + [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

```powershell
cd src/CompilerLab
dotnet run
```

发布为单文件 exe（.NET 运行时一并打包，目标机无需安装任何环境）：

```powershell
cd src/CompilerLab
dotnet publish -c Release
# 产物：bin/Release/net9.0-windows/win-x64/publish/CompilerLab.exe
```

## 使用说明

界面分五个标签页，对应编译的五个阶段：① 词法分析　② 语法分析　③ 语义分析　④ 中间代码　⑤ 解释执行结果。
左侧编辑源程序，「内置示例」下拉框可载入 7 个示例；`read` 所需数据在工具栏输入框中以空格分隔填写。
